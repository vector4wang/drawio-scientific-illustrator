# Examples

Sample diagrams produced with the `drawio-live` skill during development. These files are kept as-is for reference — they show what the tool can produce across different stacks and visual styles.

## Contents

| File | Description |
|------|-------------|
| `Classic-Microservices-Architecture.drawio` | Layered microservices reference (client → gateway → services → data) |
| `GCP-Microservices-Architecture.drawio` | GCP-flavored microservices variant |
| `SCI_architecture_diagram.drawio` | Single-cloud architecture overview |
| `SCI_architecture_diagram_cloud.drawio` | Multi-cloud architecture overview |
| `NeuralFlow_*.drawio` | AI inference platform variants (AWS and GCP) |
| `Project-Architecture-Live.drawio` | Repository's own dual-host architecture (Codex + Claude Code) |

## What these are

- **Reference outputs**, not maintained templates. The recommended starting point for new diagrams is the [AWS 3-Tier template](../templates/01-aws-3tier-webapp/template.drawio), which is a deliberately designed reference for the design system.
- The PNG previews are embedded exports that show the rendering at the time of generation.
